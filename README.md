# Beda3ty Store 🛒

**Beda3ty Store** is a modern, comprehensive e-commerce mobile application built with **Flutter**. It provides a seamless shopping experience with a focus on performance, clean code, and intuitive user interface.

## 🚀 Features

* **Product Browsing:** Effortlessly explore various categories with a smooth UI.
* **Advanced Search:** Quick and efficient search functionality to find products easily.
* **Dynamic Cart System:** Real-time cart management (Add/Remove/Update items).
* **Responsive Design:** Optimized for various screen sizes with Light/Dark mode support.
* **Streamlined Checkout:** An intuitive user journey from product selection to order placement.
